# M0 — камера и движение

Технический стенд: путник 1,1 м, WASD, вращение и приближение камеры, возврат за спину, пауза при потере фокуса. Участок содержит стволы, арку и склон. Геометрия условная; художественная приёмка леса относится к M1.

WebGPU выбран основным рендером. Если его инициализация недоступна, приложение включает WebGL2. Явный выбор неподдерживаемого WebGPU показывает кнопку перехода на WebGL2. Конфигурация сцены и движение общие для обоих режимов.

## Проверки

Логика камеры и столкновений проверяется вместе с остальными модулями через `npm run check` (68 тестов). Все 16 браузерных проверок прошли на готовой сборке (8 сценариев × 2 режима). Сценарии проверяют движение, потерю фокуса, управление камерой, шесть ракурсов, арку, сохранение дистанции после выхода из неё, склон, полный оборот у ствола и запасной рендер. Команда: `npm run test:browser`.

Видеопроверка выявила зависание камеры за аркой: устранено разделением проверки движения камеры при ходьбе и вращении на месте. Добавлена регрессия фактической дистанции до героя после арки; 16 браузерных проверок повторно прошли.

После переноса в локальную папку выполнены чистая установка `npm ci`, проверка типов и данных, все 68 тестов и сборка. Это подтверждает восстановление зависимостей и работу из нового пути на macOS.

## Замер на Mac

MacBook Air M3, 8 ГБ RAM, Chrome 151.0.7922.109, видимое окно, внутренний рендер 1280×720. Итоговая версия сцены: `m0-2`, после исправления сопровождения камеры у арки. Для каждого режима: 30 секунд прогрева, затем три одинаковых прохода по 60 секунд. Измеряются интервалы requestAnimationFrame, а не чистое время работы GPU. Исходные результаты находятся в `evidence/performance-*.json`.

| Режим | Медиана кадра | P95 в трёх проходах | Ошибки / пересечения камеры |
|---|---|---|---|
| WebGL2 | 16,7 мс (около 60 FPS) | 18,2 / 18,2 / 18,2 мс | 0 / 0 |
| WebGPU | 16,7 мс (около 60 FPS) | 18,2 / 18,2 / 17,9 мс | 0 / 0 |

В последнем проходе WebGPU было 3 кадра длиннее 33,34 мс; в остальных проходах и у WebGL2 — 0. Причина единичных задержек отдельно не установлена.

Заметного выигрыша WebGPU в M0 не обнаружено: медианы одинаковы, P95 отличается не более чем на 0,3 мс. Это последовательные замеры обычного рабочего Mac, без изоляции фоновой нагрузки. WebGPU оставлен основным по выбранному направлению развития после успешной проверки; WebGL2 остаётся рабочим запасным режимом. Данных для обещания ускорения или экономии батареи нет.

Сцена у входа: около 16,7 тысяч активных треугольников, 86 вызовов отрисовки. Эти показатели зависят от видимости объектов.

## Ограничения

- Частота экрана ограничивает наблюдаемую скорость примерно 60 FPS; равенство FPS не доказывает равную предельную производительность движков.
- Маленькая сцена не устанавливает бюджет для подробного M1. Потребление энергии, память GPU и длительная утечка памяти отдельно не измерялись.
- Столкновения используют консервативные прямоугольные объёмы: около округлых объектов возможен небольшой зазор. Это осознанное упрощение M0.
- На GitHub Actions успешно выполнены установка, 68 тестов, проверка типов/данных и сборка на Windows и Linux: [запуск CI](https://github.com/amchercashin/drevlepuscha/actions/runs/34214665431). Реальная прогулка и WebGPU на компьютере с Windows ещё не проверены. Для переноса нужны исходники и lockfile, затем `npm ci` на целевой системе; переносить `node_modules` нельзя.
- Удобство управления и художественное направление принимает Александр после самостоятельной прогулки.
