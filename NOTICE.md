# Материалы и распространение

Публикуется технический прототип с процедурной геометрией. Художественные изображения из исходного комплекта v0.3 в публичную историю и сборку не включены. Проект не является официальным продуктом правообладателей Средиземья.

`references/private/` содержит переданные художественные ориентиры и концептуальные доски. Они остаются только локально, исключены из публичной истории Git и не предназначены для runtime или папки public. Предыдущая локальная история с этими файлами сохранена отдельно вне репозитория. Установка поля `private` в package.json блокирует обычную публикацию npm-пакета, но не защищает от публикации через Git или хостинг.

Происхождение и статус проверки материалов описаны в references/README.md и references/sources.json. Для каждого нового игрового ассета сохранять источник, автора, условия использования, исходный файл и экспорт. Решение о внешнем распространении принимать по конкретному составу материалов; сам факт наличия референса в архиве не является разрешением.
