# Материалы и распространение

Проект подготовлен для внутренней разработки. Архив v0.3 не содержит подтверждённого разрешения на публичное распространение изображений, карт или производного проекта.

`references/private/` содержит переданные художественные ориентиры и концептуальные доски. Они входят в локальную историю для полного переноса между компьютерами, но не предназначены для runtime, папки public или публичного репозитория. Установка поля `private` в package.json блокирует обычную публикацию npm-пакета, но не защищает от публикации через Git или хостинг.

Происхождение и статус проверки материалов описаны в references/README.md и references/sources.json. Для каждого нового игрового ассета сохранять источник, автора, условия использования, исходный файл и экспорт. Решение о внешнем распространении принимать по конкретному составу материалов; сам факт наличия референса в архиве не является разрешением.
