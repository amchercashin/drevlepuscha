# Древлепуща

Браузерная прогулка от третьего лица по древнему лесу. Сейчас два направления разработки:

- [Шоукейс](https://amchercashin.github.io/drevlepuscha/) — лесные ложбины 512 × 640 м; здесь отрабатываем графику, дизайн, растительность и освещение.
- [Карта 1:1](https://amchercashin.github.io/drevlepuscha/?scene=world) — авторская география, стриминг большого мира и переходы между местами.

Отдельная область будущей игры — [Брендивинский мост](https://amchercashin.github.io/drevlepuscha/?scene=region&region=brandywine-bridge): 4 × 4 км рек, холмов, лесов и полей, два моста, ворота, управляемые лодки, эпизод с путником и выслеживание трёх лазутчиков. Активная версия рисуется непосредственно через WebGPU/WGSL; география и размещение объектов отделены от рендерера для будущих регионов. E — взаимодействие, M — карта, 1/2 — лук и меч, ЛКМ — атака, Ctrl — тихий шаг. Добавлены модели моста, построек и растительности Meshy, луговой покров CC0 и связный дальний лес. [Топография и граф](https://amchercashin.github.io/drevlepuscha/regions/brandywine-bridge/preview/region-viewer.html), [состояние и запуск](content/regions/brandywine-bridge/README.md), [ведомость будущих моделей Meshy](docs/regions/brandywine-bridge/MESHY-ASSETS.md).

В шоукейсе основной персонаж — следопыт Meshy: встроенные ходьба и бег, рост 1,78 м, прежняя скорость перемещения. Кнопка «Пригласить друзей» создаёт комнату на шестерых и копирует ссылку. Гости появляются рядом с ведущим; у каждого случайное имя над головой. Ведущий держит вкладку открытой.

Материал земли, свет, камера и технические параметры собраны в раскрывающемся меню «Настройки».

В шоукейсе звучат отдельные слои воздуха, крон и подлеска, птицы, насекомые и редкие древесные события. Дождь и ливень имеют отдельные звуки, которые плавно следуют погоде из настроек; в сильный дождь птицы и насекомые стихают. Звук включается после входа в лес; «Общая громкость» — в «Настройки → Звуки леса», 0% выключает звук. Сила ветра и порывы берутся из той же системы, которая двигает растительность; состав звуков следует времени суток. Работает в одиночной прогулке и комнате. [Устройство и текущие кандидаты](docs/SHOWCASE-AUDIO.md).

Для комнаты без браузерного ведущего запустите `npm run server` и откройте выданное приглашение. Node.js хранит общие часы и участников; постоянная ссылка переживает перезапуск. В такой комнате доступен P2P-голос с добровольным включением микрофона. [Запуск, перенос и ограничения](docs/PERSISTENT-ROOM.md).

Для другого компьютера есть [пошаговые команды PowerShell для Windows](docs/PERSISTENT-ROOM.md#windows-установка-и-запуск): установка Git и Node.js, скачивание проекта, запуск и обновление сервера.

Решения шоукейса переносим на большую карту отдельной задачей. Проверяем ту сцену, над которой работаем, затем публикуем и передаём визуальную оценку пользователю. M0, старый M1, эксперимент Lite и страницы отдельных деревьев сохранены как вспомогательные материалы и не входят в обычные прогоны.

Обе активные сцены находятся в одном репозитории. Последняя интеграция карты 1:1 уже вошла в `main`; рабочая ветка карты — `codex/old-forest-map-walk`. При продолжении задачи учитывайте текущую ветку и локальные изменения.

Обычная прогулка в шоукейсе на `/` рисуется непосредственно через WebGPU API и WGSL в `src/native/`: рельеф, деревья и подлесок, анимированный следопыт, карта теней, облака, лунные фазы, дождь и HDR-тональная обработка. Брендивинский мост по обычному адресу также использует прямой WebGPU/WGSL. Экспериментальный режим фауны `?debug=1&wildlife=1`, карта `?scene=world` и старый стенд региона `?scene=region&region=brandywine-bridge&renderer=babylon&debug=1` используют Babylon.js поверх WebGPU. При недоступности WebGPU приложение сообщает об этом; запасного WebGL 2 нет.

Рельеф шоукейса сохраняет прежние высоты и коллизии: двухметровая общая сетка получает локальную сетку с шагом 0,5 м вокруг следопыта. Поверхность использует прежние карты почвы, листьев, нормалей и высоты; POM постепенно выключается с расстоянием. Папоротники, траву и лесной покров готовит отдельный worker из прежних фиксированных seed; настройки ветра двигают кроны и подлесок. Панель сравнения материалов осталась во вспомогательном старом стенде.

## Запуск

Версия Node указана в `.node-version`. При первой установке или изменении зависимостей выполните `npm ci`, затем `npm run dev`.

Шоукейс открывается по корневому адресу сервера, карта — с `?scene=world`. Если данные большой карты ещё не подготовлены или изменена география, выполните `npm run world:build`.

Для Брендивинского моста дополнительно выполните `npm run region:build`, адрес — `?scene=region&region=brandywine-bridge`. `npm run test:region` проверяет его данные и игровую логику; `npx playwright test region-direct.spec.mjs` — активный игровой сценарий в браузере.

## Работа и публикация

Выберите только нужную проверку: `npm run test:showcase` или `npm run test:map`. Они проверяют базовую работоспособность одной сцены; запуск после каждой мелкой правки не обязателен. Проверка изменённой логики может ограничиваться конкретным модульным тестом. Подробности — в [рабочем процессе](docs/DEVELOPMENT.md).

Push в `main` публикует игру через GitHub Pages после CI. CI выполняет одну проверку и сборку на Linux; он не запускает браузерные, мобильные или визуальные прогоны.
