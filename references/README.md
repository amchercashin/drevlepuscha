# Художественные референсы и источники

Файлы предназначены для внутренней работы. Они остаются локально в `references/private/`, исключены из публичного Git и не нужны для сборки. При работе с художественными материалами на другой машине их нужно передать отдельно по закрытому каналу. Права на внешнее распространение и авторство оригинальных файлов отдельно не проверялись; сведения ниже отражают исходный комплект.

| Файл в private | Роль и ограничение |
|---|---|
| 01_dragon_reference.jpeg | В комплекте назван рисунком Толкина. Ритм линий, цвет и орнамент; дракон не входит в ближайший план. |
| 02_hobbit_cover_reference.png | В комплекте назван обложкой Толкина. Крупные массы и графические силуэты, без обязательства воспроизводить надписи. |
| 04_river_reference_large.jpeg | Основной ориентир леса: корни, серые стволы, своды крон, вода и масштаб фигур. Дубликат сюжета 03 оставлен только в исходном ZIP. |
| 05_gameplay_concept.png | По данным комплекта, сгенерированная концептуальная доска. Её наземные фрагменты полезны для настроения; высокий региональный вид, интерфейс, цитаты и карта не задают требования. |
| 06_asset_bible_concept.png | По данным комплекта, концептуальная доска моделей. Полезна для обсуждения силуэтов и вариаций; это не готовые модели и не обязательный перечень производства. |

Концепты 05–06 не являются скриншотами игры. Первичные рисунки визуально проще концептов; сохранять приоритет крупных форм, а не плотность украшений. Разрешение изображения и его присутствие в комплекте не подтверждают точность цвета или право использовать его как текстуру.

Старый SVG не перенесён: он вручную дублировал предварительные позиции объектов и мог расходиться с JSON. Будущую диагностическую карту строить из данных, явно показывая авторское происхождение геометрии.

[Реестр источников](sources.json) различает первичные источники, ожидающие сверки, вторичные справочники и авторские данные. Книга и конкретная базовая карта в комплекте отсутствуют. Ни одна позиция в нормализованной схеме не получила метрическую или каноническую точность при этой подготовке.
