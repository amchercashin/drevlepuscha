# Лунная поверхность

`source/moon-generated.png` — исходное изображение, приложенное пользователем 18 сентября 2026 года для этого задания. Художественная генерация здесь не выполнялась.

`moon-albedo.png` — 512 × 512 RGB, подготовленный командой `node tools/prepare-moon-texture.mjs`. Полный диск обрезан по рамке, цвет внутреннего края радиально продолжен за аналитическую маску, чтобы чёрный фон не попал в mipmaps. Скрипт использует только Node, исходник сохраняется без изменений.

V переворачивается один раз в WGSL. `Texture.invertY=false`, `useSRGBBuffer=false`; пользовательский шейдер использует численные RGB напрямую, как процедурный fallback. Нет запечённого ореола или терминатора. Маска диска, слабое затемнение края и ореол задаются шейдером.

В этой поставке используется PNG напрямую: cwebp на машине не найден. Источник добавлен в точечный фильтр `tools/prepare-runtime-textures.mjs`; при доступном cwebp обычный `npm run textures:prepare` подготовит WebP и manifest. Фиктивной записи в manifest нет.
