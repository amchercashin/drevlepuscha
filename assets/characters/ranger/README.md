# Следопыт Meshy

`meshy.glb` — неизменённый пользовательский `Meshy_AI_Meshy_Merged_Animations.glb`:
28 458 треугольников, один скелет из 28 костей, три встроенные JPEG-текстуры,
14 клипов. Blender для подключения не требуется.

Включение только в шоукейсе: `?ranger=meshy`. Обычная ссылка сохраняет
процедурного героя и не загружает GLB или его загрузчик.

`src/runtime/ranger.ts` использует `Walking`, `Running` и неподвижный `restpose`
при остановке, с плавным смешиванием. В позе покоя руки опущены программно:
повороты плеч, рук и кистей усреднены по циклу ходьбы, чтобы убрать махи;
корпус и ноги сохраняют исходную стойку. Сам GLB не изменяется.
Оба выбранных цикла идут на месте;
клип `run_fast_2` с поступательным движением не включён. Анимации лука сохранены
в исходном файле, но не запускаются.

Весь скелет с мешем масштабируется с исходных 1,70 м до 1,78 м и разворачивается
по направлению движения. Скорости контроллера остаются 1,85 и 15 м/с.
Частота шагов следует фактическому перемещению (включая остановки у препятствий):
исходный темп условно соответствует 1,5 м/с для ходьбы и 4,5 м/с для бега.
Поэтому на полном беге клип воспроизводится примерно в 3,33 раза быстрее.
Пауза останавливает анимацию. Контакт стоп с отдельными неровностями не подгоняется.
