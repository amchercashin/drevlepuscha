# Следопыт

Авторская модель пользователя из `Meshy_AI_ranger_body_rig_biped.zip`.
Для шоукейса подготовлен `ranger.glb`: один меш, один скелет из 22 костей,
одна цветовая текстура JPEG 2048 × 2048, циклы `Idle`, `Walk`, `Run`.
Масштаб — метры, исходный рост приведён к 1,78 м; в движении рост меняется с позой.

Исправлены завышенные смещения суставов исходного рига. Циклы пересобраны с
фиксированной длиной конечностей, узкой постановкой стоп, умеренными движениями
корпуса и расслабленными кистями. Немного расправлены кончики перчаток.
Самосвечение материала отключено, чтобы герой получал освещение сцены.

Это обычная скелетная анимация: отдельных костей пальцев и симуляции ткани нет.
Циклы рассчитаны на ровную опору; приспособление каждой стопы к неровному рельефу
потребует отдельной игровой IK. Художественную оценку движения делает пользователь.

Пересборка в Blender 5.2:

```sh
blender --background --python tools/prepare-ranger.py -- --source /path/to/Meshy_AI_ranger_body_rig_biped.zip
```

Готовый GLB записывается сюда. Редактируемый файл `tmp/ranger/ranger.blend` сохраняет
полную исходную текстуру. ZIP, промежуточные файлы и Blender-файл не входят в
публичную сборку и Git. Исходный архив пользователя не изменяется.
