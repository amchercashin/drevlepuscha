## Выявленные противоречия

В исходнике `docs/10_VERTICAL_SLICE.md` сохранял высокую камеру с pitch 35–65°; актуальные `docs/04_CAMERA_AND_INPUT.md` и `ADR-004` уже описывали третье лицо и взгляд вверх. На странице 4 PDF визуально подтверждены старые 35–65°, FOV 30° и запрет горизонта. Поэтому обзор нельзя было оставлять действующей инструкцией.

Общий M1/M2 требовал речную излучину и мост, а Drevlepuscha D2 — путь от High Hay до Bonfire Glade. В новом плане художественный образец находится на будущем лесном маршруте. Речные данные сохранены исключительно как синтетический тестовый пример.

Семь записей `poi.json` назывались каноническими, хотя собственное предупреждение файла признавало позиции предварительными. Теперь происхождение геометрии — авторское, а сведения о существовании объектов ожидают проверки по первоисточникам. Связи с главами — указатели для будущей сверки, не заявление, что книга была проверена.

## Изменения программной основы

- Закреплены локальный TypeScript 5.8.3, Node 22.23.1 и npm 10.9.8; добавлены lockfile, проверка типов и диагностика ресурсов. Системное ПО не обновлялось.
- Сохранение v2 использует `travel-third-person` или `atlas`, `yawDeg`, `pitchDeg`, `distanceM`. Отрицательный pitch допустим; в геометрии камеры согласован знак. Пример v1 был тестовой заготовкой, существующих игровых сохранений в пакете нет. V1 теперь явно отклоняется без изменения входных данных; автоматическая миграция не добавлена.
- Валидируются новые данные Древлепущи и конфигурация камеры, уникальность ID, происхождение и ссылки на источники. Региональные файлы из manifest действительно проверяются; проверяются границы и их порядок.
- Схема и декодер согласованы по уникальности открытых объектов. Добавлены регрессии найденных ошибок и фиксированные векторы детерминированного алгоритма.
- Реестр запланированных ассетов соответствует единственному лесному маршруту; ни одна запись не объявлена готовой моделью.
- Начальные настройки рендера учитывают фактический Mac; целевые показатели остаются неизмеренными.

## Проверки

Исходный комплект: `npm run check` на установленном Node 22.23.1 — 43 теста. Старый check не включал локально закреплённый TypeScript и новые JSON Древлепущи.

Подготовленная основа: `npm ci` и `npm run check` — проверка типов, семь JSON-контрактов с семантическими проверками, 61 тест. `npm run doctor` подтвердил работу локальной диагностики. TypeScript и node_modules занимают около 22 МиБ; графические инструменты не устанавливались.

Из отдельной чистой копии в пути с кириллицей и пробелами повторно выполнены `npm ci` и `npm run check`: установка успешна, 61 тест, проверка типов и данных пройдены. Локальные Markdown-ссылки разрешаются; коллизий имён файлов без учёта регистра нет. Это проверка на macOS ARM, а не испытание Windows.

Итог: 47 актуальных файлов, из них семь Markdown, около 7,5 МиБ исходников и референсов без Git и node_modules. После установки оставалось около 11,8 ГиБ свободного места; разница с первоначальным замером включает текущую активность системы, а не только этот проект. Реальный Windows, браузерная сцена, графика и FPS на этом этапе не проверялись.
