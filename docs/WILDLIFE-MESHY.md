# Meshy для фауны

Проверено 19.09.2026: официальный пакет `@meshy-ai/meshy-mcp-server@0.5.1`, npm repository `meshy-dev/meshy-mcp-server`; реальные MCP initialize, tools/list (24 инструмента), check_balance выполнены. Платные задачи не создавались. Это аудит возможностей, не подтверждение качества моделей.

Установка пользовательская: `C:\Users\amche\.codex\tools\meshy`. Codex запускает `serve.mjs`, который расшифровывает Windows DPAPI-секрет в окружение дочернего официального MCP. В репозитории, игровых зависимостях и публичной сборке ключа нет. Полные схемы сохранены рядом в `capabilities.json`. В текущей сессии протокол проверен через MCP SDK/stdio; игровой код и Node комнаты к Meshy не обращаются.

## Выбор для игры

Первый кандидат: один подготовленный референс → `meshy_image_to_3d`, явный `ai_model: meshy-7`, `model_type: standard`, `topology: triangle`, без Ultra, без humanoid pose. Сохранить модель до remesh (`save_pre_remeshed_model`) вместе с результатом. Сетка треугольная: пользователь отдельно сообщил о неудовлетворительном качестве предыдущих quad-персонажей. Риг и движения птицы/белки/косули выполняются в Blender.

По описанию установленной схемы Meshy 7 стоит 20 кредитов за геометрию, 30 с обычными текстурами; это заявленная стоимость, не фактическое списание. 2K исходные текстуры уменьшаются локально до игрового бюджета, без 8K и дополнительных PBR-карт для первой проверки. Количество полигонов — промежуточная цель, итоговые треугольники измеряются после экспорта. В MCP 0.5.1 обработчик не передаёт `remove_lighting` явному Meshy 7: обещать удаление baked lighting по этому параметру нельзя.

Smart Topology (`meshy-t2`, 5 за геометрию / 15 с текстурами по схеме) дешевле и разделяет части, но это не доказательство правильных суставов или пригодности для деформации. Не расходовать бюджет на сравнительные варианты до оценки первого Meshy 7. Multi-image принимает 1–4 согласованных вида; имеет смысл только при неясном силуэте. Ultra и Smart Topology в multi-image не поддерживаются. Прямой text-to-3D остаётся вариантом черновика, использует Meshy 5/6, а не Meshy 7. Deprecated lowpoly игнорирует часть контроля сетки и не выбран.

## Все группы возможностей

| Инструменты | Применение в этой работе |
|---|---|
| `meshy_text_to_3d`, `meshy_text_to_3d_refine` | Альтернатива черновика и отдельного текстурирования; не основной путь |
| `meshy_image_to_3d`, `meshy_multi_image_to_3d` | Основной путь и опциональные согласованные дополнительные виды |
| `meshy_text_to_image`, `meshy_image_to_image` | Создание/правка референсов, включая несколько видов; nano-banana/pro |
| `meshy_remesh` | Исправление плотности и topology; отдельная учитываемая операция |
| `meshy_retexture` | Один стиль: текст, изображение или 1–4 вида объекта; сохранение UV доступно |
| `meshy_rig`, `meshy_animate` | Не использовать для животных: пригодность не подтверждена; выбран Blender |
| `meshy_convert`, `meshy_resize` | По схеме по 1 кредиту; обычный игровой экспорт/масштаб дешевле выполнить в Blender |
| `meshy_uv_unwrap` | По схеме 5 кредитов, GLB ≤40 тысяч граней; не заменяет локальную проверку UV |
| `meshy_get_task_status`, `meshy_list_tasks`, `meshy_cancel_task` | Возобновление конкретной задачи; не повторять создание после таймаута |
| `meshy_download_model`, `meshy_list_models` | Сохранение GLB/изображений и поиск принятых результатов; не все форматы сразу |
| `meshy_check_balance` | Чтение баланса; не доказывает стоимость отдельной задачи при параллельных работах |
| `meshy_send_to_slicer`, `meshy_analyze_printability`, `meshy_repair_printability`, `meshy_process_multicolor`, `meshy_creative_lab` | Печать/сувениры; для игровых животных не нужны |

Общий разрешённый лимит — **400 кредитов**, включая ref/remesh/retexture и исправления. Один платный job за раз. До каждого создания записать параметры, предполагаемую стоимость и запас лимита; task_id сохранить сразу после ответа. Неопределённый ответ требует проверки существующих задач, а не новой оплаты. Общий клиент MCP имеет встроенные повторы сетевых запросов: после сбоя создания обязательно сверять task list. Результаты и история хранятся в `.artwork/wildlife/`, без ключей и без публикации временных download URL.

Источники: [официальная интеграция Meshy](https://docs.meshy.ai/en/api/ai), [официальный MCP](https://github.com/meshy-dev/meshy-mcp-server), [настройка MCP в Codex](https://developers.openai.com/codex/mcp), установленный tools/list 0.5.1. Возможности веб-интерфейса не считаются возможностями MCP.
