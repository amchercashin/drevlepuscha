# Постоянная комната и голос

## Запуск

Нужен Node из `.node-version` и зависимости из lockfile (`npm ci` после обновления зависимостей).

```sh
npm run server
```

Процесс выводит приглашение на опубликованный шоукейс. Откройте ссылку и отправьте друзьям. Сервер не запускает браузер, Babylon или графику. Остановка — Ctrl+C. Компьютер должен оставаться включённым и не спать; автозапуск не устанавливается.

Для разработки запустите `npm run dev`, затем в другом терминале:

```sh
npm run server -- --client-url http://127.0.0.1:5173/
```

`--client-url` меняет только адрес клиента в приглашении. Игровое соединение идёт через Trystero/WebRTC. Обнаружение использует существующие MQTT-брокеры и STUN. TURN не настроен, связь через произвольные сети не гарантируется.

## Windows: установка и запуск

Команды ниже предназначены для PowerShell на Windows x64. Реализация проверена на Mac; запуск на Windows пока не проверялся.

### Первый запуск

Установите Git и закреплённую в проекте версию Node.js:

```powershell
winget install --id Git.Git --exact --source winget

Invoke-WebRequest "https://nodejs.org/dist/v22.23.1/node-v22.23.1-x64.msi" -OutFile "$env:TEMP\node-22.23.1.msi"
Start-Process "$env:TEMP\node-22.23.1.msi" -Wait
```

Пройдите установщик Node.js. Затем закройте PowerShell и откройте заново, чтобы стали доступны установленные команды.

```powershell
cd $HOME
git clone --depth 1 https://github.com/amchercashin/drevlepuscha.git
cd drevlepuscha

node --version
npm.cmd ci
npm.cmd run server
```

`node --version` должен вывести `v22.23.1`. Если проект уже скачан, повторный `git clone` не нужен: перейдите в его каталог.

Терминал выведет приглашение — его можно открыть на другом компьютере и отправить друзьям. Если брандмауэр Windows запросит разрешение для Node.js, разрешите доступ в используемой сети. Держите терминал открытым; остановка — Ctrl+C.

### Последующие запуски

```powershell
cd "$HOME\drevlepuscha"
npm.cmd run server
```

### Обновление проекта

Сначала остановите сервер сочетанием Ctrl+C, затем выполните:

```powershell
cd "$HOME\drevlepuscha"
git pull --ff-only
npm.cmd ci
npm.cmd run server
```

На новом компьютере по умолчанию создаётся новая комната. Чтобы перенести прежнюю, остановите сервер на Mac и до первого запуска на Windows скопируйте его `.server-data/room.json` в `$HOME\drevlepuscha\.server-data\room.json`, создав каталог `.server-data`, если его ещё нет. Файл `room.lock` не переносите. Одновременно запускать одну комнату на двух компьютерах не нужно.

## Сохранение и перенос

`.server-data/room.json` содержит идентификатор комнаты, ключ доступа, закрытый ключ сервера и временную опору. Каталог исключён из Git; его нельзя помещать в `public/` или публиковать вместе с клиентом. Приглашение даёт доступ к комнате — делитесь им только с участниками.

День длится 20 минут и при создании начинается с полудня. Время идёт без игроков и учитывает перерыв между запусками. После перезапуска прежняя ссылка остаётся рабочей; позиции игроков сбрасываются. WebRTC peer ID может измениться — клиент подтверждает сохранённую идентичность сервера по подписи.

Для переноса остановите процесс, безопасно скопируйте `room.json` на машину с проектом и Node, затем запустите `npm run server -- --data-dir /путь/к/каталогу`. Не запускайте две копии одной комнаты. На одной машине повторный запуск блокируется `room.lock`; после аварии блокировка снимается при подтверждении завершения прежнего процесса. Повреждённое состояние автоматически не заменяется: восстановите резервную копию. `room.lock` переносить не нужно.

## Архитектура и границы

Сервер ведёт шесть участников и принятые позиции, проверяет формат, диапазоны, последовательность и частоту сообщений. Сам он не имеет аватара. Движение и столкновения рассчитывает клиент: это ещё не серверная физика и не защита от изменённого клиента.

Ядро `PersistentWorld` не загружает транспорт, графику или файловую систему. Серверный адаптер отвечает за Trystero и сохранение комнаты; клиентская сессия — за связь с игрой. Для перехода на Colyseus можно заменить адаптеры. Серверная симуляция движения потребует общей геометрии коллизий и коррекции клиента отдельной задачей.

В пустой комнате нет игрового тика. С участниками снимки отправляются с частотой 15 Гц; медленное соединение не накапливает очередь снимков. Потеря сервера вызывает переподключение, браузеры не назначают нового ведущего. При первоначальном поиске и переподключении через 15 секунд без доступных релеев или через 40 секунд без подключения к серверу показывается ошибка. На экране входа можно повторить попытку или продолжить одному; позднее успешное подключение принимается, пока пользователь не вышел из поиска. Одиночная прогулка и прежние комнаты с браузерным хостом сохранены. Реализация касается шоукейса.

## Голос

«Подключить голос» включает прослушивание; «Включить микрофон» запрашивает доступ для разговора. До этого микрофон не используется. Можно выключить микрофон, заглушить собеседника или выйти из разговора.

Аудио передаётся между браузерами в отдельной комнате Trystero. Игровой сервер не принимает и не записывает звук. Допускаются только текущие игроки. При потере игровой сессии голос отключается и микрофон освобождается; после восстановления подключитесь кнопкой снова. Отказ в разрешении не мешает игре или прослушиванию.

Если браузер заблокировал воспроизведение, нажмите «Воспроизвести звук». Пространственного звука, записи и видео нет. Микрофон требует HTTPS либо localhost. Реальные микрофоны, другие сети и шесть одновременно говорящих участников требуют отдельных проверок.

## Адресная проверка

`npm run test:server` проверяет ядро, сохранение и подписанную идентичность без сети. `npx playwright test persistent-room.spec.mjs` явно запускает две сцены, тестовое аудио, перезапуск Node и возврат в пустую комнату. Сценарий использует публичные MQTT/STUN и не входит в обязательный CI.
