## W2 — программные критерии пройдены (19.09.2026)

- `WildlifeSession` разделяет владельца и реплику; передача solo → host сохраняет сам экземпляр ядра. Выход из комнаты восстанавливает видимые состояния в новой solo-эпохе, без повторения событий; это не сохранение полной индивидуальной истории.
- Capability `wildlife-v1` проверяет realm/contentHash/behaviorVersion. Кадры ограничены 32 KiB UTF-8, ID/state/site/route проверяются до применения, старые seq/epoch отвергаются. Новая эпоха принимается только в приветствии известного владельца. Несовместимость показывается текстом.
- Решения выполняются один раз в существующем тике комнаты; гостевые кадры хранятся до загрузки 3D. Есть общие часы браузерного хоста и ограниченная поправка RTT. Меню/атлас не останавливают общую симуляцию. Loading-клиенты исключены из наблюдателей, в том числе после замены страницы постоянной комнаты.
- Один и тот же тестовый эпизод работает solo, host/guest и в Node. Node использует подготовленный JSON без GPU/DOM, после restart создаёт новую authorityEpoch и сохраняет прежнее приглашение/идентичность сервера. Пустая комната не тикает.
- Общий renderer принимает абсолютные ENH и origin, не знает границ шоукейса. Использует общий FrameWorkBudget, реальные списки теней/quality/dispose. Один ярко-розовый примитив и надпись «ТЕСТОВАЯ МОДЕЛЬ» доступны только с `debug=1&wildlife=1`; это не художественная птица. Голубые линии маршрутов включаются отдельно через `m0.wildlife.setProbe(true)`.
- В живой сцене полностью совпали каталог 4372 деревьев и порядок obstacle ID, отдельно bounds 18 props. Для обзора птицы используются приближённые стволы/props, для проверки полётного коридора — полная исходная геометрия.
